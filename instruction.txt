Overview

Your board represents the Referee Unit, controlling and monitoring two games:
Game 1 – Red Light, Green Light
Game 2 – Catch & Run
Each game tests different aspects of awareness, precision, and stability. Players are tracked using onboard sensors, and outcomes are indicated through LED paerns and UART
messages. The user push buon (PB) controls mode transions. Each group can choose to be a Player or an Enforcer.
Peripherals Used
User Push Buon (PB): Used to switch modes or confirm game events.
Temperature, Humidity and Pressure Sensor: Simulate environmental changes in the surroundings (e.g., humidity spike = tension or chase intensity). Used as secondary thresholds.
Accelerometer & Gyroscope: Detects player movement or lt: crical in Red Light, Green Light for judging if the player moved during “Red Light.”
Magnetometer: Acts as a proximity detector to the Enforcer during Catch & Run. Stronger readings mean the Enforcer is closer.
UART Transmission: Sends updates, warnings, and status to the referee unit.
LED: Visual game indicator based on phase and outcome.
 
Modes of Operaon
Game 1 – Red Light, Green Light 
When powered on, the device enters Red Light, Green Light as the default starng mode.
1. Startup Message via UART:
"Entering Red Light, Green Light as Player/Enforcer"
2. Game Overview:
Every 10 seconds, the game command alternates between "Green" and "Red" light phases (not the LED2 colour).
During Green Light, players can “move” freely.
During Red Light, the accelerometer and gyroscope monitor for any movement above a defined threshold of your choice.
3. Gameplay (Green Light):
For both PLAYER and ENFORCER:
 UART
Sends once:  "Green Light!"
Environment monitoring: Temperature, Pressure and Humidity sensors readings transmied via UART every 2 seconds.
LED: Always ON.
4. Gameplay (Red Light):
For both PLAYER and ENFORCER:
 UART:
Sends once:  "Red Light!"  
Movement monitoring: Accelerometer and Gyroscope readings transmied via UART every 2 seconds.
LED: Toggles every 0.5 seconds.
PLAYER: If the Accelerometer and Gyroscope readings exceed thresholds of your choice
UART sends once:  "Game Over"
Game ends
ENFORCER: If the Accelerometer and Gyroscope readings exceed thresholds of your choice
UART sends once:  "Player Out!"
Game connues
5. Switch Game:
Double-press user pushbuon: Switch to Catch & Run (Game 2).
Game 2 – Catch & Run 
Once switched, the unit enters Catch & Run Mode, a chase simulaon between Player and Enforcer.
1. Startup Message via UART:
"Entering Catch And Run as Player/Enforcer"
2. Game Overview:
Magnetometer connuously checks the magnec field strength, signifying the proximity between the player and the enforcer.
The player is trying to run from the enforcer, and the enforcer is trying to catch the player
Environment Monitoring (for both Player and Enforcer): Temperature, Pressure and Humidity sensors are read every 1 second but only transmied via UART when the
readings exceed defined thresholds. Transmission stops when the values return to normal. Example:
"Temperature spike detected! T:35C. Dangerous environment!"
3. Gameplay (PLAYER):
When the magnec field exceeds a defined threshold (simulang the Enforcer nearing the Player):
UART:  "Enforcer nearby! Be careful."
LED blinks faster as proximity increases. (You may implement your own blinking effect. A minimum of 3 different blinking frequencies should be used).
If user pushbuon single-press is detected within 3 seconds of threshold violaon of magnetometer
UART: " Player escaped, good job! "
Game connues
If user pushbuon single-press is NOT detected within 3 seconds of threshold violaon of magnetometer
UART: " Game Over! "
Game ends
4. Gameplay (ENFORCER):
When the magnec field exceeds a defined threshold (simulang the Enforcer nearing the Player):
UART: " Player is Nearby! Move faster. "
LED blinks faster as proximity increases. (You may implement your own blinking effect. A minimum of 3 different blinking frequencies should be used).
If user pushbuon single-press is detected within 3 seconds of threshold violaon of magnetometer
UART: " Player captured, good job! "
Game connues
If user pushbuon single-press is NOT detected within 3 seconds of threshold violaon of magnetometer
UART: " Player escaped! Keep trying. "
Game connues
5. Switch Game:
Double-press user pushbuon: Switch to Red Light, Green Light (Game 1)
