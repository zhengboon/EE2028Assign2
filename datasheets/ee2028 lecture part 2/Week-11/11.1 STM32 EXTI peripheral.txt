EXTI INTRODUCTION
 •   The EXTI manages the external and internal asynchronous events/interrupts and
     generates the event request to NVIC
 •   Interrupts from other chips/devices (e.g., accelerometer, pressure sensor) cannot be
     connected directly to NVIC- they have to be forwarded/taken in through GPIO Pins =>
     EXTI => NVIC
 •   The EXTI allows the management of up to 40 interrupt/event requests, including 26
     configurable lines

EXTI REGISTER: EXTI_IMR1
 •   Interrupt mask registers: Address Offset = 0x00 (n=1) : RW
 •   Bits 31:0 IMx: Interrupt Mask on line x (x=31 to 0)
     •   0: Interrupt request from Line x is masked, i.e., disabled (default for EXTI0-15)
     •   1: Interrupt request from Line x is not masked
 •   EXTI line 0-15: GPIO configurable lines. We do not care about bits 31:16 while
     configuring GPIO EXTI lines

EXTI REGISTER: EXTI_RTSR1
 •   Rising trigger selection registers: Address Offset = 0x08 (n=1) : RW
 •   Bits 31:23 and 17: Reserved, must be kept at reset value
 •   Bits 22:18 and 16:0 RTx: Rising trigger event configuration bit of line x (x=22 to 18,
     and 16 to 0). We do not care about bits 31:16 while configuring GPIO EXTI lines
     •   0: Rising trigger disabled for input line
     •   1: Rising trigger enabled for input line




                                                                                                                                         8

                                                                    © Copyright National University of Singapore. All Rights Reserved.
EXTI REGISTER: EXTI_FTSR1
 •   Falling trigger selection registers: Address Offset = 0x0C (n=1) : RW
 •   Bits 31:23 and 17: Reserved, must be kept at reset value
 •   Bits 22:18 and 16:0 FTx: Falling trigger event configuration bit of line x (x=22 to 18,
     and 16 to 0). We do not care about bits 31:16 while configuring GPIO EXTI lines
     •   0: Falling trigger disabled for input line
     •   1: Falling trigger enabled for input line
 •   EXTI_RTSR and EXTI_FTSR can be set for the same interrupt lines

EXTI REGISTER: EXTI_PR1
 •   Pending registers: Address Offset = 0x14 (n=1) : rc_w1 (read/write 1 to clear)
 •   Bits 31:23 and 17: Reserved, must be kept at reset value
 •   Bits 22:18 and 16:0 PIFx: Pending interrupt flag on line x (x=22 to 18, and 16 to 0).
     We do not care about bits 31:16 while configuring GPIO EXTI
     •   0: No trigger request occurred
     •   1: Selected trigger request occurred
 •   This bit is set when the selected edge event arrives on the interrupt line.
 •   This bit is cleared by writing a ‘1’ to the bit

CONFIGURATION AND HANDLING OF EXTI
 •   Configuration steps:
     •   Enable AHB2 bus for the GPIO port(s)
     •   Configure SYSCFG_EXTICRn to choose Port Pin as source of the specific EXTI line
     •   Configure EXTI_IMRn to enable the specific EXTI line
     •   Configure EXTI_RTSRn or/and EXTI_FTSRn to choose the Rising or Falling edge (or both) trigger
     •   Enable specific interrupt request (IRQ) in NVIC

 •   Once the settings are done, the user program
     need not ‘call’ the handler, it will be invoked by
     the hardware automatically
 •   At the end of handler, should clear the interrupt
     flag by writing to the pending register
     EXTI_PRn
