INTERRUPT SET ENABLE REGISTERS (ISER) AND
INTERRUPT CLEAR ENABLE REGISTERS (ICER)
 •   NVIC_ISER (32 bits, RW) is used to
     •   Enable interrupts
     •   Determine which interrupts are currently enabled and disabled
 •   NVIC_ICER (32 bits) is used to
     •   Disable interrupts
     •   Determine which interrupts are currently enabled and disabled
 •   NVIC can have more than one NVIC_ISER/NVIC_ICER. Each bit of the registers is
     corresponding to one interrupt
 •   Enable/Disable an interrupt:
     •   To enable an interrupt (set enable bit), write 1 to NVIC_ISER
     •   To disable an interrupt (clear enable bit), write 1 to NVIC_ICER

INTERRUPT SET PENDING REGISTERS (ISPR) AND
INTERRUPT CLEAR PENDING REGISTERS (ICPR)
•   NVIC_ISPR (32 bits) register is used to
    •   Force interrupts into pending state
    •   Determine which interrupts are currently pending (R/W)
•   NVIC_ICPR (32 bits) register is used to
    •   Clear pending interrupts
    •   Determine which interrupts are currently pending (R/W)


•   NVIC can have more than one NVIC_ISPR/NVIC_ICPR and each bit is
    corresponding to one interrupt input
•   Interrupt pending status can be accessed through NVIC_ISPR/NVIC_ICPR
    •   To pend an interrupt, write 1 to corresponding bit in NVIC_ISPR
    •   To cancel a current interrupt pending, write 1 to corresponding bit in NVIC_ICPR
                                                                                                                                               5
    •   Writing to NVIC_ISPR has no effect on an interrupt which is already pending
                                                                          © Copyright National University of Singapore. All Rights Reserved.

    •   Writing to NVIC_ICPR has no effect on the active status of an interrupt.
INTERRUPT PRIORITY REGISTERS (IPR) AND
INTERRUPT ACTIVE BIT REGISTERS (IABR)
 •   NVIC Interrupt Priority Registers (IPRs) are 8-bit registers, though only some of the
     MSBs are implemented depending on the SoC
 •   Accessible as IP[i], where i=0 to 94 for STM32 as there are 95 external interrupts
 •   Each register is used to assign a priority level (from 0 to 255) to interrupts: 0 is the
     highest programmable priority

 •   Read NVIC_IABR to determine which interrupts are active. Each external interrupt has a
     bit in NVIC_IABRs
 •   When CPU starts an interrupt handler, its active bit is set to 1, and then cleared when
     return is executed
 •   If two interrupts are nested, both are active
     •   Active = has started, has not finished. An interrupt being active doesn’t necessarily mean that
         the processor is currently executing the ISR
                                                                                                                                               6
 •   NVIC_IABRs for external interrupts are read only

REGISTERS FOR SYSTEM EXCEPTIONS
  •       So far, we saw the various NVIC registers which deals with external interrupts. For system
          exceptions, the corresponding controls are considered a part of the System Control Block
          (SCB – a core peripheral) rather than NVIC
  •       SHPR: System Handler Priority Register are used to set Priority of system exceptions with
          programmable priority levels, accessible as SHP[i], where i=0 to 11 for all CM4 chips
  Self-

  •       ICSR: Interrupt Control and State Register (ICSR) can be used to
          •   Set and clear the pending status of system exceptions including SysTick, PendSV, and NMI
          •   Determine the currently executing exception/interrupt number by reading VECTACTIVE
  •       SHCSR: System Handler Control and State Register (SHCSR)
          •   Usage faults, memory management (MemManage) faults, and bus fault exceptions are enabled
              by the SHCSR

PRIMASK, FAULTMASK AND BASEPRI
•     PRIMASK is a 1-bit register (default = 0)
      •    When it is set, it allows only NMI, hard fault, and reset exceptions. Other interrupts and
           exceptions (having PRI >= 0) are masked (disabled)
•     FAULTMASK is a 1-bit register (default = 0)
      •    When it is set, it allows only NMI and reset. All the interrupts and exceptions including hard
           fault exception (having PRI >= -1) are masked
•     BASEPRI is an 8-bit unsigned register
      •    used to disable all exceptions/interrupts having PRI >= BASEPRI. Writing a 0 to BASEPRI
           disables BASEPRI
