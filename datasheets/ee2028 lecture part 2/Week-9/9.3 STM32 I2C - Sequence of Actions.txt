 only when there is a potential of change of direction after the current read/write

Writing Size (<=255) bytes via autoincrement (Size excl. MemAddress byte)
        •         RELOAD mode is used for the write below, but it could be done without RELOAD if Size <= 254, as 1 byte is
                  needed for MemAddress byte (i.e., the slave register address)
        •         Using RELOAD allows the driver functions for read and write to be similar

CONCLUSION
 •   Sequence of Actions
     •   Interplay between CR2 and ISR registers
     •   Reading and Writing slave registers
     •   Autoend
         •   Not enabled for Change of direction (Read after Write)
         •   Enabled for all other cases
     •   Reload
         •   Memory (or Slave Register) Address and Bytes to be transferred
         •   Bytes to be transferred > 255 bytes
 •   Code Walkthrough
