CONTROL REGISTER 1 (USART_CR1)                                                          Note that FIFO mode is disabled




                           Address offset: 0x00, Reset value: 0x0000 0000
•   OVER8: Oversampling mode
    •      0: Oversampling by 16 (better reliability)
    •      1: Oversampling by 8 (higher speed possible)
•   M1, M0 : Word length
    •      M[1:0] = 00: 8 data bits;         01: 9 data bits;         10: 7 data bits
•   PCE: Parity control enable
    •      This bit selects the hardware parity control (generation and detection). When the
           parity control is enabled, the computed parity is inserted at the MSB position (9th
                                                                                                                                                    3
           bit if M=1; 8th bit if M=0) and parity is checked on the received data
                                                                               © Copyright National University of Singapore. All Rights Reserved.

        OVER8, M1, M0, PCE, PS can only be written when the USART is disabled (UE=0)

CONTROL REGISTER 3 (USART_CR3)




                            Address offset: 0x08, Reset value: 0x0000 0000

•   ONEBIT: One sample bit method enable
    •      Specifies whether a single sample or three samples' majority vote is selected
           •    0: Three sample bit method
           •    1: One sample bit method
    •      Selecting the single sample method increases the receiver tolerance to clock
           deviations
    •      When the one sample bit method is selected the noise detection flag (NF) is
           disabled                                                                                                                                   7

CONTROL REGISTER 3 (USART_CR3)




                            Address offset: 0x08, Reset value: 0x0000 0000
•   Bits that should be kept cleared when asynchronous mode is used
    •      SCEN: Smartcard mode enable; HDSEL: Half-duplex selection; IREN: IrDA mode
           enable
•   EIE: Error interrupt enable
    •      Error Interrupt Enable Bit is required to enable interrupt generation in case of a
           framing error, overrun error or noise flag (FE=1 or ORE=1 or NF=1 in the
           USART_ISR register)

RECEIVE DATA REGISTER (USART_RDR)



                    Address offset: 0x24, Reset value: 0x0000 0000


•   Bits 31:9 -> Reserved, must be kept at reset value.
•   Bits 8:0 -> 9-bit receive data : Receive data value
    •   The content from the SIPO (receive) shift register which samples the RX line is
        copied into this register once a complete byte is received
    •   When receiving with the parity enabled, the value read in the MSB bit is the
        received parity bit

                                                                                                                                          11

                                                                     © Copyright National University of Singapore. All Rights Reserved.
TRANSMIT DATA REGISTER (USART_TDR)



                    Address offset: 0x28, Reset value: 0x0000 0000


•   Bits 31:9 -> Reserved, must be kept at reset value
•   Bits 8:0 -> 9-bit transmit data : Transmit data value
    •   The content is copied into the PISO (transmit) shift register which sends the
        data serially through TX
    •   When transmitting with the parity enabled (PCE bit set to 1 in the USART_CR1
        register), the value written in the MSB (bit 7 or bit 8 depending on the data
        length) has no effect because it is replaced by the parity

INTERRUPT AND STATUS REGISTER (USART_ISR)



                     Address offset: 0x1C, Reset value: 0x0200 00C0                   Note that FIFO mode is disabled

•   Contains various status and interrupt status bits
    •   Set by the hardware, generally cleared due to some action by the software
        •   Some bits are cleared when appropriate registers are read (e.g., reading
            USART_RDR clears RXNE) /written (e.g., writing USART_TDR clears TXE as well as
            TC)
        •   Some bits are cleared by writing to Interrupt Clear Register (USART_ICR, not
            covered in the lecture, but easy). For example, ORE is cleared by writing to ORECF
            of USART_ICR
        •   Some bits are automatically set and cleared (e.g.: BUSY)                                                                         13

INTERRUPT AND STATUS REGISTER (USART_ISR)



                   Address offset: 0x1C, Reset value: 0x0200 00C0                 Note that FIFO mode is disabled

  •   If a bit in this register becomes 1, and the corresponding interrupt is enabled in
      USART_CRx, the interrupt is sent to NVIC and the interrupt handler will be
      triggered
  •   There is only one interrupt from each USART interface to NVIC
  •   If not using interrupts, these bits can be polled by the software as status bits

INTERRUPT AND STATUS REGISTER (USART_ISR)



                     Address offset: 0x1C, Reset value: 0x0200 00C0                 Note that FIFO mode is disabled
•   BUSY: Busy flag
    •   This bit is set and reset by hardware. It is active when a communication is
        ongoing on the RX line (successful start bit detected)
    •   It is reset at the end of the reception (successful or not)
•   TXE: Transmit data register empty
    •   This bit is set by hardware when the content of the USART_TDR register has
        been transferred into the transmit shift register
    •   It is cleared by a write to the USART_TDR register
                                                                                                                                           15
    •   An interrupt is generated if the TXEIE bit =1 in the USART_CR1 register

INTERRUPT AND STATUS REGISTER (USART_ISR)



                     Address offset: 0x1C, Reset value: 0x0200 00C0                 Note that FIFO mode is disabled
•   TC: Transmission complete (both TDR and transmit shift register
    empty)
    •   This bit is set by hardware if the transmission of a frame containing data is
        complete and if TXE is set
    •   It is cleared by software, writing 1 to the TCCF in the USART_ICR register or by
        a write to
    •   the USART_TDR register
    •   An interrupt is generated if TCIE=1 in the USART_CR1 register

INTERRUPT AND STATUS REGISTER (USART_ISR)



                    Address offset: 0x1C, Reset value: 0x0200 00C0                 Note that FIFO mode is disabled
•   RXNE: Read data register not empty
    •   This bit is set by hardware when the content of the receive shift register has
        been transferred to the USART_RDR register
    •   It is cleared by a read to the USART_RDR register. The RXNE flag can also be
        cleared by
    •   writing 1 to the RXFRQ in the USART_RQR (not covered in the lecture) register
    •   An interrupt is generated if RXNEIE=1 in the USART_CR1 register

INTERRUPT AND STATUS REGISTER (USART_ISR)



                     Address offset: 0x1C, Reset value: 0x0200 00C0                 Note that FIFO mode is disabled
•   ORE: Overrun error
    •   Set by hardware when the data currently being received in the shift register is
        ready to be transferred into the RDR register while RXNE=1. It is cleared by a
        software, writing 1 to the ORECF, in the USART_ICR register. An interrupt is
        generated if RXNEIE=1 in the USART_CR1 register or EIE = 1 in the
        USART_CR3 register
    •   Note: When this bit is set, RDR register content is not lost but the shift register
        is overwritten

                                                                      © Copyright National University of Singapore. All Rights Reserved.
INTERRUPT AND STATUS REGISTER (USART_ISR)



                    Address offset: 0x1C, Reset value: 0x0200 00C0                 Note that FIFO mode is disabled
•   NE: START bit Noise detection flag
    •   Set by hardware when noise is detected on a received frame. It is cleared by
        software, writing 1 to the NFCF bit in the USART_ICR register
    •   This bit does not generate an interrupt during single-buffer communication as it
        appears at the same time as the RXNE bit which itself generates an interrupt

INTERRUPT AND STATUS REGISTER (USART_ISR)



                     Address offset: 0x1C, Reset value: 0x0200 00C0                 Note that FIFO mode is disabled
•   FE: Framing error
    •   Set by the hardware when the stop bit is not recognized on reception at the
        expected time
    •   Caused due to de-synchronization (not sampling bits at the correct time),
        excessive noise, or a break character (0s for a frame period)
    •   It is cleared by software, writing 1 to the FECF bit in the USART_ICR register. An
        interrupt is generated if EIE = 1 in the USART_CR3 register

                     Address offset: 0x1C, Reset value: 0x0200 00C0                 Note that FIFO mode is disabled
•   PE: Parity error
    •   This bit is set by hardware when a parity error occurs in receiver mode. It is
        cleared by software, writing 1 to the PECF in the USART_ICR register. An
        interrupt is generated if PEIE = 1 in the USART_CR1 register
